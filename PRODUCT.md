# Product

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
Delegated by the user and confirmed in the implementation plan: Astro, TypeScript, React islands, Tailwind CSS, shadcn/ui, Pagefind, static Sites hosting.

## Users
Glenelg Country School FBLA high-school students preparing for 2026–2027 competitions, primarily Maryland Central District.

## Product Purpose
Make each event easy to find and its published test objectives understandable through focused original lessons. A student should not need to read an entire textbook. Practice reinforces reading.

## Operating Context
District tests November 9–12, submissions October 31, Central District conference November 21, 2026; sourced and checked October 27. All 76 events, with district/state/national differences.

## Capabilities and Constraints
Readable topic lessons and quick reviews first; search, filters, official FBLA sample-test links, independent lesson checks, flashcards, rehearsal timers, checklists, local progress and export/import. Event practice uses FBLA CONNECT rather than independently authored test simulations. CONNECT blocks embedding with X-Frame-Options: DENY and frame-ancestors 'self'; direct links select each event’s test without searching the course menu. Students use their own FBLA login; this site never handles CONNECT credentials or scores. Earlier local quiz results remain labeled and exportable. No site accounts or private Drive credentials. Source conflicts remain visible.

## Brand Commitments
Study-handbook design, warm neutral surfaces, navy and teal, strong typography and generous reading space. User approved the plan and delegated aesthetic implementation.

## Evidence on Hand
Current Maryland guides for all 76 events, national roster, 43 directly linked MBA Research guides, public educational references. All 274 inventoried historical Drive files are accessible in 227 grouped entries. Folder names, checked event aliases and explicit related-skill mappings associate archive entries with 38 current events. Every event has a materials page; events without an archive match say so. Historical contents and answers remain unverified. No fabricated outcome claims.

## Accessibility & Inclusion
Keyboard-accessible, responsive, WCAG AA text contrast; readable without client JavaScript; reduced-motion support.
