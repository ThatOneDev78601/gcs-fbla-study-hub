## Structure the document with styles

A business document should have a clear purpose, audience, and hierarchy. Use paragraph styles for headings and body text instead of repeatedly applying font changes. Styles make global changes consistent and can support an automatic table of contents. Paragraph spacing controls space around paragraphs; line spacing controls space within them. Use page breaks to start a new page deliberately. Use a section break when part of a document needs a different orientation, header, footer, or numbering scheme. Repeated blank lines are an unstable layout method.

## Handle tables, correspondence, and variable data

Tables align related information using rows and columns; tabs or strings of spaces rarely survive changes reliably. Repeat header rows across pages where appropriate and avoid splitting a short logical record unnecessarily. A business letter needs the requested date, recipient, salutation, message, closing, and sender information in the required format. Mail merge combines a main document with a structured data source to create personalized outputs. Verify field names, filters, and representative records before producing the entire batch.

> **Example**
>
> You need to send a personalized invitation to twelve members from a spreadsheet.
>
> Create a main invitation with merge fields for name and event date. Connect the source, preview the first, last, and a record with a long name, then merge to a new output and check pagination.

## Inspect the final output

Check spelling and grammar while also verifying meaning, names, numbers, and dates. Automatic correction can change a correct specialized term. Inspect headers, footers, page numbering, margins, widow/orphan control, and table wrapping in print preview. Use meaningful heading structure and alternative text when the output format supports accessibility. Export to the requested format, reopen the exported file, and confirm that links, symbols, and page breaks survived. A file that looks correct in the editing window may produce a different printed result.

- Practice task: format a two-page business report using heading styles, a table, a header, and page numbers; export it as a PDF.
- Common mistake: formatting every heading separately, then missing one during a revision.

## Key terms

**Paragraph style.** A reusable collection of paragraph and text-formatting settings.

**Section break.** A division that permits different page-level formatting within one document.

**Mail merge.** Combining a main document and data records to personalize outputs.
