## Understand what travels with the file

A static copy preserves a snapshot of information. Later source changes do not update it automatically. A linked object refers to a source location and can refresh, but the link may break when a source moves or access changes. An embedded object stores content within the destination file; this can make a package more self-contained but may increase file size. Choose based on the required workflow, not the option that happens to look similar on screen.

## Preserve meaning across applications

When moving spreadsheet output into a document or presentation, keep the same units, time period, definitions, and rounding policy. A copied value can look like a percentage while becoming text, or a large number can be truncated by a narrow display. Use destination formatting when it improves consistency without changing meaning. For a mail merge, keep one record per row and stable field headers in the source. Preview unusual names, blank fields, and dates before completing a batch.

> **Work through an example**
>
> A report includes a linked quarterly revenue chart. The spreadsheet is renamed after the report is delivered.
>
> The link may stop refreshing. Keep source paths stable when linking is required, or provide a verified self-contained embedded/static version when the deliverable calls for portability. Label the data period and reopen the final files on the intended device.

## Verify the package as a recipient

A final check should follow the recipient’s actions: open the document, read the chart, inspect a cited figure, print or present, and follow a relevant link. Compare totals and labels against the source. Check print areas and page breaks in the document as well as the workbook. In slides, test readability from presentation view. Reopen exported PDFs because they may flatten active objects or change layout. Keep filenames clear, remove temporary working files from the submission package, and submit only the formats requested by the event.

- Practice task: build a spreadsheet chart, place it into a report and a slide deck, change one source value, and observe which outputs update.
- Common mistake: checking only the source workbook while the delivered document contains an older copied chart.

## Key terms to remember

**Linked object.** Content that refers to an external source location and may update from it.

**Static copy.** A snapshot that does not automatically track later source changes.

**Self-contained package.** Deliverable files that carry the information they need without unavailable source paths.
