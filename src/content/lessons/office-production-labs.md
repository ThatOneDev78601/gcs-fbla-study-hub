## Word processing skills

Use styles (Heading 1, Heading 2, Normal) instead of formatting text by hand. Styles keep formatting consistent, let you change every heading at once, and build an automatic table of contents. Set margins, orientation, and paper size in Layout. A section break lets one part of a document have different orientation, columns, or headers; a page break simply starts a new page. Headers and footers can hold page numbers, which can start at a specific number or use a different first page.

Tables organize data: insert, merge, and split cells, repeat the header row on each page, and align numbers to the right or on the decimal. Tabs with leaders (dots) create neat lists such as a table of contents. Edit with Find and Replace, check spelling and grammar, and use the official Production Test Reference Guide for letter, memo, report, and citation formats required by the event.

1. Mail merge: start a letter, choose Select Recipients and use an existing list such as the practice sales file.
2. Insert merge fields, such as "Dear «Rep»," and a sentence using «Region» and «Product».
3. Preview several records, checking spacing and number formats.
4. Finish and merge to a new document or to printing, and save both the main document and the result.

## Presentation skills

Edit the slide master to set fonts, colors, logos, and layouts for every slide at once. Use layouts with content placeholders rather than loose text boxes. SmartArt and drawing tools create diagrams such as process flows and organization charts; align and distribute shapes for a clean look. Insert images and crop or remove backgrounds; compress pictures to reduce file size. Add audio or video and set it to play automatically or on click.

Speaker notes hold talking points that the audience does not see. Action buttons and hyperlinks jump to a specific slide, such as returning to an agenda. Use simple transitions and animations only where they help explain a sequence. Export as PDF for handouts or as a video when the event requires it, and test the exported file.

## Integrate applications

Linking and embedding move data between applications differently. A linked object stays connected to its source file: when the spreadsheet changes, the chart in the document updates, but the source file must travel with the document. An embedded object is a copy stored inside the document: it travels with the file but does not update when the source changes. Paste Special offers both choices, along with pasting as a picture or as values.

Review tools support collaboration. Track Changes records every edit so others can accept or reject it. Comments ask questions without changing text. Compare merges two versions. Before final export, accept or reject all changes, delete comments, inspect the document for hidden personal information, and proofread once more on paper or at a different zoom level.

> **Example**
>
> A manager wants a one-page report with a chart that will update when next month's sales are added to the workbook.
>
> Create the chart in the spreadsheet, copy it, and use Paste Special, Paste Link in the document. Keep both files in the same folder. When the workbook changes, update the link in the document. If the report will be emailed without the workbook, embed the chart or paste it as a picture instead, accepting that it will not update.

## Timed production practice

Production tests reward accuracy and following directions under time pressure. Read all instructions before starting, note every required element, and save often with the required file names. If a step is unclear, complete what you can and keep moving.

1. Workbook (15 minutes): from the practice sales file, add the Revenue column, a South bonus flag, a pivot table of revenue by region and product, and a column chart of revenue by region.
2. Report (15 minutes): write a one-page memo to the sales manager in the reference guide's memo format, with a heading style, a two-sentence summary, a table of the top three sales, and the linked chart.
3. Presentation (10 minutes): build three slides on the master (title, results with the chart, next steps) with speaker notes and an action button returning to the title.
4. Review (5 minutes): check spelling, formulas, links, file names, and that each requirement is met; export the memo as PDF.

> **Try it yourself**
>
> Complete the 45-minute task above, then self-check: total revenue $2,401.25; South revenue $675.00; top three sales Planner (Blake) $300.00, Pen pack (Blake) $270.00, Planner (Avery) $264.00; two South bonus rows. List any requirement you missed and the reason.

## Key terms

**Style.** A saved set of formatting applied to text consistently across a document.

**Section break.** A break that lets parts of a document have different layout settings.

**Slide master.** The template controlling the design and layouts of all slides.

**Linked object.** Content that stays connected to its source file and updates when the source changes.

**Embedded object.** A copy of content stored inside a file that does not update from its source.

**Track Changes.** A feature that records edits so they can be reviewed, accepted, or rejected.
