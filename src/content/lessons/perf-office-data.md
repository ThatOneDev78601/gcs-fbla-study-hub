## Understand the task and data

Identify the requested output, audience, required format, source data, calculations, and deadline. Preserve an unmodified source when working on practice files. Check data types, missing values, duplicates, units, and date conventions before analysis. Sort complete records together so names and figures do not become disconnected. For data-analysis presentations, define the question and appropriate comparison before selecting a chart or computing every available statistic.

## Build accurate calculations and readable outputs

Spreadsheet formulas start with references and operators; functions such as SUM, AVERAGE, IF, and COUNTIF solve common tasks. Relative references change when copied; absolute references fix a location. Use number formats appropriately but remember that formatting does not change the underlying value. Word-processing styles create consistent headings and paragraphs; tables, page breaks, headers, and footers support structured documents. Slides need readable charts and a clear message rather than pasted spreadsheet clutter.

> **Example**
>
> A worksheet calculates each item’s total as quantity times unit price and applies a tax rate stored in cell H2. Copying the formula changes H2 to H3 and H4.
>
> Use an absolute reference such as $H$2 for the shared rate, verify a sample calculation manually, and check totals. Label whether amounts include tax before reusing the table in a document or slide.

## Integrate and verify

Choose whether linked, embedded, or static content fits the task and software instructions. Links may update but can break when source files move; static copies need deliberate refreshing. Use appropriate charts: bars compare categories, lines show ordered time trends, and scatterplots explore relationships. Explain what a chart shows and what it cannot prove. Check formulas, totals, filters, print areas, pagination, file formats, and final exports. For production practice, use the authorized reference guide and actual software rather than only memorizing menu names.

- Common mistake: using a misleading chart scale or omitting units.
- Common mistake: sorting one column and corrupting the record relationships.
- Common mistake: trusting a copied formula without checking its references.

## Key terms

**Absolute reference.** A spreadsheet reference fixed during copying, such as $H$2.

**Data type.** The kind of value, such as number, text, date, or Boolean.

**Embedded object.** Content stored inside another document rather than only referenced by location.
