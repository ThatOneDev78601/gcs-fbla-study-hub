## Read the event requirements

Read the current event document for the season and competition stage before planning. A district report and a later live presentation are different deliverables even within one event. Record topic, eligibility, format, timing, submission method, permitted materials, and scoring criteria. Keep factual rules separate from your own preparation choices. If two official documents conflict, preserve both references and ask the adviser to resolve the discrepancy rather than inventing a combined rule.

## Build an evidence matrix

For each rubric criterion, identify the skill being judged, the work needed, and the evidence that demonstrates it. “Evaluate alternatives” requires more than naming options: define criteria, compare tradeoffs, and justify the chosen approach. A claim such as “we tested the app” needs test cases, expected results, observed results, and changes. Assign an owner and review date, then track dependencies so the final report is not written before the underlying work exists.

> **Example**
>
> A sample rubric asks for a logical recommendation, an implementation plan, and measurable evaluation. A draft contains only a recommendation slide.
>
> Add comparison evidence for the choice, a sequenced plan with owners and resources, and measures with a baseline and review date. Each addition should help a judge understand your reasoning.

## Check your work against the rubric

Self-assess using the rubric’s described performance levels and point to the exact supporting evidence. Separate completed work, planned work, assumptions, and estimates. Explain limitations rather than fabricating data or results. Practice examples in this hub teach methods; competitors must create their own competition work and follow the event’s assistance rules. Before submitting, open the exported file and check the event requirements. Make sure judges can find your evidence and view it on the required equipment.

- Common mistake: organizing entirely around personal preference while omitting a scored requirement.
- Common mistake: assuming a heading proves the skill beneath it.
- Common mistake: treating a preparation suggestion as an official rule.

## Key terms

**Evidence matrix.** A mapping from criteria to work products and proof.

**Dependency.** A task or condition that another task relies on.

**Deliverable.** A specific artifact or performance that must be produced.
